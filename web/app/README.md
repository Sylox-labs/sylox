# Sylox App

The app people use to see an issuer's risk, provide cover, buy cover, and claim. Talks to the Soroban contracts directly, through generated TypeScript bindings. No backend.

## Running it

From the repo root (this is an npm workspace member, not a standalone project):

```bash
npm install
npm run dev -w web/app
```

## Contract bindings

`lib/contracts/<name>/` is generated by `stellar contract bindings typescript`, one directory per contract, against the contract IDs in `deployments/testnet.json`. Never hand-edit the generated `src/index.ts` files; regenerate instead:

```bash
npm run bindings:generate -w web/app
```

This requires `stellar` CLI **28.1.0** exactly (the version `deploy/deploy.sh` pins) and fails loudly if a different version is installed, rather than silently generating bindings that might not match the deployed contracts' actual ABI.

`lib/contracts/deployment.ts` is the one place in the app that reads `deployments/testnet.json`; every contract client is built from it. No contract address is ever written as a literal in app code, so a testnet redeploy (new contract IDs) is a non-event for the app.

The generated bindings are committed (not gitignored): CI has no network path to regenerate them against live testnet, so it builds against the committed copy like any other source file.

## Screens

- **Explorer** (`/`): every tracked asset, its current risk band, score, staleness, and event status, read live from RiskOracle. Done.
- Asset, Event, Markets, Faucet: not built yet.

## Rules this app follows

- **Contract reads only, never recomputed.** Staleness, band, and score all come from the contract's own `check_stale`/`band`/`score` calls. The app never re-derives these from raw epoch/timestamp math, because the contract's actual staleness threshold isn't even exposed as a public read (see `lib/explorer-data.ts`'s doc comments).
- **Testnet labeled everywhere.** `components/TestnetBanner.tsx` renders on every page.
- **No marketing claims.** No "insured," no "guaranteed returns," no APY, the word "insurance" never appears.
