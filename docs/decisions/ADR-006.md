# ADR-006: Event definition content and v1 scope

Status: Accepted, spec v1.1 · Date: October 8, 2026

## Context

- Some currencies have two live exchange rates. Argentina is the standard example: the official ARS rate and the market (parallel) rate have differed by tens of percent for long periods, and at times the market rate has been more than double the official one. A `Reference::Fiat(code)` that does not say which rate it means makes "depeg" undefined for such a currency.
- An IssuerFreeze is only possible if the issuer account has `AUTH_REVOCABLE` or `CLAWBACK_ENABLED` set. v1.0 did not record these flags, so a definition could promise cover against something the issuer cannot do.
- WithdrawalHalt depends on probing anchor endpoints, which can misread a halt in either direction. v1.0 treated it like the other event types.
- v1.0 aimed to build all event types at once.

## Decision

- `Reference::Fiat` gets a rate source: `Fiat(Symbol, FxRateSource)` with `FxRateSource::{Official, Market}`. The choice is fixed in the event definition: `EventDefinition` carries a copy of the asset's `reference`, `register_definition` rejects a mismatch, and `update_asset` rejects any change to an asset's `reference`, so the copy and the oracle's configuration always agree.
- `AssetConfig` records the issuer flags as `issuer_flags: IssuerFlags { auth_revocable, clawback_enabled }`. IssuerFreeze definitions can only be registered for assets whose flags make a freeze possible (`FreezeImpossible` otherwise).
- WithdrawalHalt is documented as the least reliable event type. Its evidence is reporter probes, plus user submitted SEP-24 transactions stuck in a pending status beyond a threshold, plus anchor cooperation where available. It is Tier 2 only.
- First build scope: Depeg and IssuerFreeze, each with canonical definitions (ADR-001). Tier 2 (WithdrawalHalt) and Tier 3 (Insolvency) come in a later build phase, together with MintWithoutBacking, which is a Tier 1 flag that needs committee confirmation.

## Consequences

- A fiat referenced asset's peg is unambiguous, and an ARS token redeemable at the official rate is never judged against the market rate, or the reverse.
- Changing an asset's reference basis has no in place path; it is an open question how to migrate if an issuer changes its redemption basis.
- Buyers cannot be sold IssuerFreeze cover on an issuer that cannot freeze. If an issuer later enables a flag, governance must update `issuer_flags` before such a definition can be registered.
- Expectations for WithdrawalHalt are set honestly, and the first build stays small: two event kinds whose data is keeper posted and publicly recomputable. The data model already covers every kind, so later phases need no type changes.
- `AssetConfig` also gains `fx_adapter`, so the oracle and `require_holding` know which `FxAdapter` serves a fiat reference.
